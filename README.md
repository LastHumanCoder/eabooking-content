# EA Booking — September 2026 content

20 self-contained HTML blocks (17 pages, 3 blogs).

September 2026 content batch: 17 pages and 3 blogs for East Africa, the Gulf and Turkey. Every price and property comes from EA Booking's own live inventory.

## How to use

- `/<slug>.html` — preview in a browser.
- `/raw/<slug>.html` — the paste-ready block. Copy the whole file into the page body.
- Each block carries its own scoped CSS, its cover image embedded as base64, and FAQ JSON-LD. Two blocks can sit on one page without their styles colliding.
- The `<h1>` is inside the block. Do not add a second one in the CMS.

## Notes

- The top comment in each file carries the meta description, the page title and the target keywords from the content calendar.
